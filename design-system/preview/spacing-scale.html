page-level rhythm
4px grid Every margin, padding, and gap is a multiple of 4 — never use off-scale values (5, 7, 13).
Steps Move one step at a time; jumping (8 → 32) only between distinct regions, not adjacent elements.
Nesting Inner padding ≤ outer padding so content never crowds its container.
Use gap Space sibling rows/chips with flex/grid gap, not per-element margins.
